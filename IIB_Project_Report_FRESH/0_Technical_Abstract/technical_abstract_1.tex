\chapter*{Technical Abstract Plan}
\addcontentsline{toc}{chapter}{Technical Abstract Plan}

The final report must begin with a technical abstract of not more than two pages in length. This should be designed as a self-contained document and should provide a concise overview of the report structure and the key features of your work (e.g. the problem being addressed, techniques used, main results, and conclusions).

Focus on the model and the results rather than future work, maybe mentioning that we have lay the foundation for a future model etc.
