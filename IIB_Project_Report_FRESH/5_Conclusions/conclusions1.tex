\section{Conclusions}



The main future works I would like to focus on is to highlight the fact I have layed the foundations for building on the current model, such that these future works are logical next steps. 
My ideas for this are mainly for:
1) creating a full, multiple pulse, continuous detection system. The CANN gives a continuous readout, and so the system can be upgraded for continous tracking of distance. 
2) Feedback control. Once a continuous tracking system is operational, a control feedback loop could be impemented, i.e. the bat can move to hunt the object.
3) Velocity tracking. This can add another CANN that can use the information of how the distance information changes to track velocity.
4) Multiobject tracking: by adding the number of objects in the state space variables, we can infer whether the number of variables is best explained by more or less objects, and so using a birth-death process can enable multi-object tracking.
5) Increased complexity of biological modelling. It has been seen that modelling the biology even at a simple level can improve the performance of an SNN. A future work could explore whether this increase in complexity improves the performance further, and what the trade-offs are
6) Full trainable model. The current model is tuned by hand to achieve functionality. By implementing a model that can train the feedforward pathways, the model will likely improve further.
